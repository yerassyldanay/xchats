## Auth & users

### POST /xchats/api/v1/auth/login
- **Body:** `{ "email": "a@b.com", "password": "…" }`
- **Response:** `{ "user": { "id","email","name" }, "organization": { "id","name" } }` (sets session cookie)
- **Errors:** `VALIDATION_ERROR` (400), `UNAUTHORIZED` (401 bad creds)

### POST /xchats/api/v1/auth/logout
- **Body:** none → **Response:** `null`

### GET /xchats/api/v1/me
- **Response:** `{ "user": {…}, "organization": {…} }` · **Errors:** `UNAUTHORIZED`

### GET /xchats/api/v1/users
- **Query:** `page`, `page_size`
- **Response:** `{ "items": [{ "id","email","name","created_at" }], "page","page_size","total" }`

### POST /xchats/api/v1/users
- **Body:** `{ "email","password","name?" }`
- **Response:** `{ "id","email","name" }` (201) · **Errors:** `CONFLICT` (email exists), `VALIDATION_ERROR`

## Organization

### GET /xchats/api/v1/organization
- **Response:** `{ "id","name","auto_response_mode","auto_response_window" }`

### PATCH /xchats/api/v1/organization
- **Body (any subset):** `{ "name?", "auto_response_mode?": "NEVER|CONFIGURE_TIME|ALWAYS", "auto_response_window?": { "start":"09:00","end":"18:00","tz":"Asia/Almaty" } }`
- **Response:** the updated organization · **Errors:** `VALIDATION_ERROR`

## WhatsApp accounts (manager)

### GET /xchats/api/v1/whatsapp-accounts
- **Response:** `{ "items": [ WhatsAppAccount ] }` — **all** Evolution instances, each with `assigned` + status.

### POST /xchats/api/v1/whatsapp-accounts  (add)
- **Body:** `{ "display_name","instance_name","sync_full_history?": true }`
- **Response:** `WhatsAppAccount` (201, `connection_status: qr_required`) · **Errors:** `CONFLICT` (name taken)

### GET /xchats/api/v1/whatsapp-accounts/{id}
- **Response:** `WhatsAppAccount`

### POST /xchats/api/v1/whatsapp-accounts/{id}/qr  ·  GET …/qr
- **Body:** none.
- **Response:** `{ "status": "qr_required|connected", "qr_code": "2@…|null", "pairing_code": "WZYE…|null", "expires_at": "ts" }`
- GET is the poll variant (every 2–3s while `qr_required`).

### POST /xchats/api/v1/whatsapp-accounts/{id}/assign  ·  …/unassign
- **Body:** none → **Response:** updated `WhatsAppAccount` (`assigned: true|false`)
- **Errors:** `INSTANCE_NOT_FOUND`

### POST /xchats/api/v1/whatsapp-accounts/{id}/sync  ·  GET …/sync
- POST **Body:** `{ "scope?": "full|recent" }` → starts a sync job.
- GET **Response:** `{ "status","contacts_synced","chats_synced","messages_synced","media_pending","progress_current","progress_total","last_error" }`

## Inbox

### GET /xchats/api/v1/conversations
- **Query:** `status?`, `assignee?` (`me|unassigned|uuid`), `whatsapp_account_id?`, `q?`, `page`, `page_size`
- **Response:** `{ "items": [ Conversation ], "page","page_size","total" }`

### GET /xchats/api/v1/conversations/{id}/messages
- **Query:** `before?` (cursor ts/id), `limit?`
- **Response:** `{ "items": [ Message ], "next_before": "cursor|null" }`

### POST /xchats/api/v1/conversations/{id}/messages  (send)
- **Body (text):** `{ "type": "text", "text": "hello" }`
- **Body (media):** `{ "type": "media", "media_type":"image|video|audio|document", "media_id?":"uuid", "url?":"https://…", "caption?":"…" }` (provide `media_id` of a stored asset OR a `url`)
- **Response:** `Message` (status starts `queued`) · **Errors:** `ACCOUNT_NOT_CONNECTED` (409), `SEND_FAILED` (502), `RATE_LIMITED` (429)

### POST /xchats/api/v1/conversations/{id}/assign
- **Body:** `{ "member_id": "uuid|null" }` (null = unassign) → **Response:** updated `Conversation`

### POST /xchats/api/v1/conversations/{id}/read
- **Body:** none → **Response:** `{ "unread_count": 0 }`

### GET /xchats/api/v1/contacts  ·  GET /xchats/api/v1/contacts/{id}
- list **Query:** `q?`, `page`, `page_size` → `{ "items":[ Contact ], … }`; detail → `Contact` (+ recent conversations)

### GET /xchats/api/v1/media/{id}
- **Response:** the **binary media stream** (not the envelope); `Content-Type` per the asset. `404` if unknown, `502 MEDIA_UNAVAILABLE` if not downloadable.

## AI assistant

### GET /xchats/api/v1/assistant/config  ·  PUT …/config
- GET **Response:** the published config `{ "version","persona","topics","prices","assets" }`
- PUT **Body:** the editable config draft (same shape) → **Response:** the saved draft

### POST /xchats/api/v1/assistant/publish
- **Body:** `{ "version?": n }` → **Response:** `{ "version","published_at" }`

### POST /xchats/api/v1/assistant/playground
- **Body:** `{ "messages": [{ "role":"customer|agent","content":"…" }], "profile?": { … } }`
- **Response:** an `AiDraft`-shaped result (no send). See `8-ai-assistant.md`.

### GET /xchats/api/v1/conversations/{id}/ai-drafts
- **Response:** `{ "items": [ AiDraft ] }`

### POST /xchats/api/v1/ai-drafts/{id}/approve
- **Body:** `{ "edited_text?": "…" }` (member may tweak before sending)
- **Response:** the resulting `Message` (sent via the outbound pipeline, `sender_type: ai`)
- **Errors:** `ACCOUNT_NOT_CONNECTED`, `SEND_FAILED`

## Realtime

### GET /xchats/api/v1/realtime  (SSE)
- **Stream events** (`event:` + JSON `data:`):
  `message.created`, `message.updated`, `conversation.created`, `conversation.updated`,
  `assignment.changed`, `ai_draft.created`, `whatsapp_account.status_changed`, `sync.progress`.
- Each `data` carries the relevant entity (Message / Conversation / AiDraft / WhatsAppAccount /
  `{whatsapp_account_id, contacts_synced, …}`).

## Evolution webhook ingress

### POST /evolution/api/v1/webhook/{whatsapp_account_id}  (+ /{event} if webhookByEvents)
- **Auth:** shared token from `.env` (header or query) → `WEBHOOK_UNAUTHORIZED` (401) if wrong.
- **Body:** the raw Evolution event (e.g. `messages.upsert`, `messages.update`, `send.message`,
  `connection.update`, `qrcode.updated`, `contacts.*`, `chats.*`) — shapes in `captures/`.
- **Behavior:** store raw → enqueue → return fast.
- **Response:** `{ "payload": null, "errcode": "OK" }` (Evolution only needs a 2xx).
