# xchats

**Галлюцинациясыз AI-мен self-hosted омниарналы inbox.**
WhatsApp және Telegram — бір ортақ inbox-та. Көмекші әр жауапты сіздің білім
қорыңыз бойынша дайындайды, ал оны адам растайды. Клиент карточкалары, тапсырмалар
және жаппай жіберулер қосылған; Instagram, Messenger және WhatsApp Cloud API — жақында.

## 60 секундтық жылдам бастау

```bash
git clone https://github.com/yerassyldanay/xchats.git
cd xchats
make up
make seed
```

**http://localhost:8081** ашыңыз — `admin@xchat.kz` / `xchat-admin-change-me`
(жалпыға белгілі әдепкі құпиясөз) арқылы кіріңіз; бірінші кіргеннен кейін
бірден ауыстырыңыз.
`make seed` жергілікті инстансты Qazan Home асүй техникасы дүкенінің демо
деректерімен толтырады; пәрменді қайта іске қосу қауіпсіз.

## Басты мүмкіндіктер

- **Галлюцинациясыз жауаптар** — модель баға, күн немесе байланыс
  деректерін өзі ешқашан жазбайды. Ол `{{token}}` орынбасарын шығарады, ал
  бэкенд оны сақталған нақты мәнге ауыстырады — немесе жоба тексеруден
  өтпей, адамға беріледі.
- **Адам әрдайым бақылауда** — әр жоба тек ұсыныс. Агент «Жіберу»
  батырмасын баспайынша, клиентке ештеңе жетпейді.
- **Бір бинарник, бір файл** — Go + ендірілген SQLite. Postgres те,
  Redis те, бұлттық қызмет те қажет емес.
- **Кез келген модель** — OpenAI, Claude, Gemini, OpenRouter немесе
  Ollama арқылы жергілікті модель; провайдерді кодта емес, баптауларда
  ауыстырасыз.
- **ChatGPT / Claude арқылы баптау** — MCP-коннекторы LLM-клиентке
  құжаттарыңызды оқып, білім қорына өзгерістерді сіздің қарауыңызға
  дайындауға мүмкіндік береді.

## Визуалды тур

Барлық скриншот деректермен толтырылған Qazan Home инстансынан алынған, макеттер емес.
Олар жұмыс істеп тұрған қолданбадан `make screenshots` командасымен жаңартылады.

### 1. Кіру және алғашқы қадамдар

![Кіру беті: xchats не және оның алты мүмкіндігі](docs/images/login.png)
![Басты бет: оқылмаған чаттар, мерзімі өткен тапсырмалар және Жобадағы өзгерістер](docs/images/dashboard.png)
![Баптау шебері: клиенттер сізге қайда жазады](docs/images/setup.png)

Кіру беті xchats не екенін және не істей алатынын түсіндіреді. Кіргеннен кейін
Басты бет назар аударуды қажет ететінді көрсетеді (оқылмаған чаттар, мерзімі өткен
тапсырмалар, Жобадағы өзгерістер), ал жаңа жұмыс кеңістігі үшін — «Алғашқы қадамдар»
тізімін; баптау шебері әкімшіні ИИ кілті, алғашқы арна және білім базасы арқылы алып өтеді.

### 2. Ортақ inbox

![Клиент диалогы және дайындалған AI жауабы](docs/images/inbox.png)
![Чаттың қасындағы клиент панелі: профиль, мәртебе, тегтер, келесі қадам және жазбалар](docs/images/customer-panel.png)

WhatsApp және Telegram диалогтары бір кезекте; AI жауабы адам тексергенше жоба күйінде
қалады. Клиент панелі чаттың қасында профильді, мәртебені, тегтерді, келесі қадамды және
жазбаларды сақтайды.

### 3. Арналар және автоматтандыру

![Арна белгішелері, күйі және автоматтандыруы бар карточкалар; Meta арналары «Жақында» деп белгіленген](docs/images/channels.png)
![WhatsApp немесе Telegram таңдау; Meta арналары «Жақында» деп белгіленген](docs/images/channel-connect.png)
![Арнаның автоматтандыру диалогы және автожауап кестесінің нұсқалары](docs/images/automation.png)

WhatsApp QR-код арқылы, Telegram бот токені арқылы қосылады. Әр тіркелгі — өз арнасының
белгішесі, күйі, ИИ-кеңестер ауыстырғышы және автожауап кестесі (үнемі, түнде, демалыс
күндері немесе өз сағаттары) бар карточка. Instagram, Messenger және WhatsApp Cloud API
бэкендте іске асырылған, бірақ интерфейсте әзірге өшірулі («Жақында»); оларды қайтару үшін
фронтендті `VITE_ENABLE_META_CHANNELS=true` күйінде жинаңыз.

### 4. Білім қоры

![Білім қорындағы нақты тауар суреттері, атаулары мен бағалары бар каталог](docs/images/knowledge-base.png)
![Білім қорына шолу: көмекшінің персонасы, миссиясы, шектеулері және тіл саясаты](docs/images/knowledge-base-overview.png)

Тауарлар, тарифтер, жеткізу аймақтары, байланыстар және саясаттар — көмекші қолданатын
жалғыз фактілер, олармен бірге оның персонасы мен шектеулері. Сандар `{{token}}` арқылы
қордан қойылады; толығырақ [сызбада](docs/images/grounding.svg).

### 5. Жоба: тексеру және ChatGPT / Claude

![Тауар бағасының өзгерісі Жобада «болды / болады» карточкасы ретінде](docs/images/draft-staging.png)
![ChatGPT және Claude MCP коннекторын баптау](docs/images/mcp-connect.png)

«Жоба» беті Білім қорымен бірдей құрылымда. Сілтемелер, файлдар және MCP коннекторы оған
жазады; ChatGPT немесе Claude OAuth 2.1 авторизациясынан кейін 13 `kb_*` құралын қолданады,
бірақ әр өзгеріс «болды / болады» карточкасы ретінде көрінеді, ал жариялауды адам орындайды.

### 6. Көмекшіні тексеру

![Көмекшіні тексеруге арналған мысал сұрақтары бар симулятор беті](docs/images/simulator.png)
![Каталог туралы сұрақтар тарихы бар жеке көмекші](docs/images/assistant.png)

Клиент сұрақтарын жұмыс қорында немесе жобада тексеріңіз — нақты нөмірсіз — немесе жеке
көмекшіден жұмыс деректері мен жарияланбаған өзгерістер туралы сұраңыз. Бұл хабарлар
клиентке жіберілмейді. Модельдерді ашық [`evals/`](evals/) жинағымен салыстырыңыз.

### 7. Клиенттер және тапсырмалар

![Мәртебесі, тегтері және арна сәйкестендіргіштері бар клиенттер торшасы](docs/images/customers.png)
![Мерзімі өткен, Бүгін, Ертең және Кейін топтарына бөлінген тапсырмалар тақтасы](docs/images/followups.png)

Профиль арналарды, мәртебені, тегтер мен жазбаларды біріктіреді; тапсырмалар тақтасы мерзімі бойынша бөлінген.

### 8. Науқандар

![Жеткізу барысын тікелей көрсететін науқандар тізімі](docs/images/campaigns.png)
![Жаңа науқан шебері: аудитория, хабарлама, кесте](docs/images/campaign-wizard.png)

Үш қадамдық шебер — аудитория, хабарлама, кесте: алушыларды импорттау, үлгіні алдын ала көру,
қарқын мен жіберу терезелері; әр жеткізу мен жауап ортақ inbox-та көрінеді.

### 9. Баптаулар және команда

![ИИ-қозғалтқыш, парсерлер, мониторинг, қашықтан қол жеткізу, арналар, команда және сақтық көшірмелер баптаулары](docs/images/settings.png)
![Баптаулар: команда мүшелері және тіркелгі қауіпсіздігі](docs/images/settings-team.png)

Модельдер, парсерлер, мониторинг, қашықтан қол жеткізу, арналар, команда және сақтық
көшірмелер интерфейс арқылы бапталады.

## Бұл қалай жұмыс істейді

1. Клиент сізге WhatsApp немесе Telegram арқылы жазады.
2. Хабар бүкіл командаға ортақ **бір inbox-қа** түседі.
3. Көмекші тек бекітілген білім қоры бойынша жауап дайындайды.
4. Адам жобаны тексереді, өңдейді немесе алып тастайды — және өзі жібереді.

Толық архитектура сипаттамасы — [`docs/overview.md`](docs/overview.md)
файлында; фактілерді қою тетігі
[визуалды турда](#4-білім-қоры)
көрсетілген.

## Іске қосудың басқа жолдары

- **Бастапқы кодтан** (әзірлеу үшін): `make dev-backend` + `make dev-frontend`
  — қараңыз [`docs/release/installation.md`](docs/release/installation.md).
- **Десктоп қолданба** (Wails — Windows/macOS/Linux): `make desktop-build`
  — қараңыз [`docs/desktop.md`](docs/desktop.md).
- `make help` барлық қолжетімді командаларды көрсетеді.
