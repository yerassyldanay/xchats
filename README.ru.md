# xchats

**Self-hosted омниканальный инбокс с AI без галлюцинаций.**
WhatsApp, Telegram, Instagram и Messenger — в одном общем инбоксе. Ассистент
готовит каждый ответ по вашей базе знаний, а отправляет его всегда человек.

## Быстрый старт за 60 секунд

```bash
git clone https://github.com/yerassyldanay/xchats.git
cd xchats
make up
```

Откройте **http://localhost:8081** — войдите как `admin@xchat.kz` /
`xchat-admin-change-me` (публичный пароль по умолчанию; смените его сразу
после первого входа).

## Главные преимущества

- **Ответы без галлюцинаций** — модель никогда сама не пишет цену, дату
  или контакт. Она подставляет плейсхолдер `{{token}}`, а бэкенд заменяет его
  на точное сохранённое значение — или черновик не проходит проверку и
  эскалируется человеку.
- **Человек в контуре — всегда** — каждый черновик лишь предложение.
  Ничего не уходит клиенту, пока агент не нажмёт «Отправить».
- **Один бинарник, один файл** — Go + встроенный SQLite. Не нужен ни
  Postgres, ни Redis, ни облачный сервис.
- **Любая модель** — OpenAI, Claude, Gemini, OpenRouter или локальная
  модель через Ollama; провайдер меняется в настройках, а не в коде.
- **Настройка прямо из ChatGPT / Claude** — MCP-коннектор позволяет
  LLM-клиенту прочитать ваши документы и подготовить изменения базы знаний
  на ваше рассмотрение.

## Визуальный тур

Каждый скриншот ниже сделан прямо с работающего инстанса xchats. Здесь нет макетов.

### 1. Общий инбокс и омниканальная синхронизация

![Общий инбокс xchats: открытый диалог с сообщением клиента слева и подготовленным ответом ассистента справа](docs/images/inbox.png)

Каждый диалог из WhatsApp, Telegram, Instagram, Messenger и WhatsApp Cloud API попадает в **один общий инбокс**, где рядом ждёт готовый черновик ответа ассистента. Человек всегда принимает окончательное решение: одобрить, изменить или отклонить.

### 2. База знаний и строгая подстановка токенов

![Каталог товаров в Базе знаний с реальными фото, названиями и точными ценами](docs/images/knowledge-base.png)

База знаний хранит точные факты, по которым ассистенту разрешено отвечать — товары, цены, тарифы, зоны доставки и правила. Модель никогда не пишет числа сама: она выдаёт токен `{{token}}`, а бэкенд подставляет точное значение из базы данных. Подробнее — на [диаграмме](docs/images/grounding.svg).

### 3. Поэтапное добавление знаний и просмотр изменений (дифф)

![Страница Черновик с отображением изменений цены товара в виде до/после диффа](docs/images/draft-staging.png)

Каждое изменение — введённое вручную, импортированное из документа/URL или переданное через MCP (§7) — сначала попадает в область черновиков с наглядным диффом до/после. Ничто не попадет в рабочую базу знаний без явной проверки и публикации человеком.

### 4. Мини-CRM и доска ежедневных задач (Follow-ups)

![Сетка клиентов с карточками профилей, статусами, тегами и арнальными идентификаторами](docs/images/customers.png)
![Доска задач с группировкой по Просрочено, Сегодня, Завтра и Позже](docs/images/followups.png)

Каждый контакт получает карточку в CRM — статус, теги, заметки и привязку ко всем каналам в одном месте. Каждое обещание превращается в задачу, сгруппированную по категориям: **Просрочено, Сегодня, Завтра и Позже**.

### 5. Рассылки с отслеживанием доставки в реальном времени

![Список рассылок с активной кампанией и прогрессом доставки](docs/images/campaigns.png)

Загрузите список получателей, напишите шаблон сообщения, и xchats выполнит рассылку с ограничением скорости и интервала отправки. Статус доставки отслеживается в реальном времени, а ответы клиентов попадают в общий инбокс.

### 6. Встроенный симулятор каналов и AI-тесты

![Экран симулятора с примерами вопросов для тестирования ассистента](docs/images/simulator.png)

Симулятор позволяет проверить, как именно ассистент ответит на вопрос клиента — по **рабочей** базе знаний или по **черновику** — без подключения реальных номеров WhatsApp или Telegram. В связке с тестовым модулем ([`evals/`](evals/)) можно автоматически оценивать качество ответов.

### 7. Настройка xchats через ChatGPT / Claude Desktop по протоколу MCP

Подключите ChatGPT или Claude Desktop к своему инстансу xchats как MCP-коннектор (**Черновик → ChatGPT / Claude**), авторизуйтесь один раз через OAuth 2.1 с PKCE, и ассистент сможет считывать переданные вами документы и предлагать структурированные факты через 13 `kb_*` инструментов. Все изменения отправляются в **ту же область черновиков** (§3).

## Как это работает

1. Клиент пишет вам в WhatsApp, Telegram, Instagram или Messenger.
2. Сообщение попадает в **один инбокс**, общий для всей команды.
3. Ассистент готовит ответ строго по одобренной базе знаний.
4. Человек проверяет, редактирует или отклоняет черновик — и отправляет сам.

Полное описание архитектуры — в [`docs/overview.md`](docs/overview.md);
механизм подстановки фактов показан в
[визуальном туре](#2-база-знаний-и-строгая-подстановка-токенов).

## Другие способы запуска

- **Из исходников** (для разработки): `make dev-backend` + `make dev-frontend`
  — см. [`docs/release/installation.md`](docs/release/installation.md).
- **Десктопное приложение** (Wails — Windows/macOS/Linux): `make desktop-build`
  — см. [`docs/desktop.md`](docs/desktop.md).
- `make help` покажет все доступные команды.

> [!WARNING]
> Канал WhatsApp подключается как WhatsApp Web (без комиссии Business API),
> но это неофициальный клиент — начните с номера, потерю которого вы можете
> себе позволить. Подробности — в [визуальном туре](#1-общий-инбокс-и-омниканальная-синхронизация).
