## Copyleft dependencies — read this section first

Two dependencies are not permissively licensed. Both come in through
[`go.mau.fi/whatsmeow`](https://github.com/tulir/whatsmeow) (MPL-2.0, WhatsApp
connectivity):

### `go.mau.fi/libsignal` — GPL-3.0

Pulled in transitively by whatsmeow (not a direct dependency of this repo).
Confirmed via `go list -deps ./cmd/xchats | grep libsignal`: roughly two
dozen of its packages (`ecc`, `groups`, `cipher`, `kdf`, `session`, `state`,
...) are statically linked into the `xchats` binary whenever WhatsApp
connectivity is built in — which is always, in this repo's default build.

This is the reason xchats is licensed AGPL-3.0-only rather than
MIT/Apache-2.0: a GPL-3.0 dependency statically linked into a distributed
binary rules out permissive licensing of that binary, regardless of this
project's own license preference. GPL-3.0 and AGPL-3.0 are explicitly
compatible with each other (see the FSF's [GPL/AGPL compatibility FAQ
entry](https://www.gnu.org/licenses/gpl-faq.en.html#AGPLGPL)), so this
dependency did not force AGPL specifically — GPL-3.0-only would also have
been legally workable. AGPL-3.0 was chosen as project policy: it closes a
gap GPL-3.0 leaves open (running a *modified* version as a hosted service
never counts as "distribution," so a hosted competitor running a modified
xchats would owe nothing back under plain GPL). Get a licensing-competent
lawyer to confirm this reasoning before leaning on it in a dispute.

**What AGPL-3.0 §13 does and doesn't require of a self-hosted deployment:**
it activates for *unmodified* self-hosting the same as any other
copyleft license — no extra obligation there. It activates further, and
specifically, for a *modified* version run as a network service: anyone
*interacting with it over the network* — which includes an organization's
own employees using an internally modified deployment, not only external
users — must be offered that modified source. It does not have to be
published publicly; it has to be offered to the people who use it over the
network.

Complete corresponding source for every release — this repository's source
at that tag, plus the source of every Go module statically linked into the
binary (`go mod vendor`'d, so `libsignal` included) — is attached to the
matching [GitHub Release](https://github.com/yerassyldanay/xchats/releases)
as `xchats-<tag>-corresponding-source.tar.gz`. Since xchats ships its own
complete source publicly, running an *unmodified* build already satisfies
§13 independent of that asset; the asset exists for the modified-deployment
case, and for convenience and auditability generally.

### `go.mau.fi/whatsmeow` and `go.mau.fi/util` — MPL-2.0

File-level weak copyleft: modifications to MPL-licensed *files themselves*
must stay MPL-2.0 and be made available, but this does not extend to other
files that merely import them (unlike GPL/AGPL). xchats does not currently
modify either module (no `replace` directive in `backend/go.mod`), so the
practical obligation is limited to reproducing the license text and pointing
at the upstream source — both satisfied by this file and the full texts in
[`THIRD_PARTY_LICENSES.txt`](THIRD_PARTY_LICENSES.txt).

## Maintaining this file

Regenerate whenever dependencies change meaningfully (a new direct
dependency, a major version bump, especially anything touching
`go.mau.fi/*`):

```bash
make notices
```

This runs [`scripts/notices.sh`](scripts/notices.sh), which regenerates
[`THIRD_PARTY_LICENSES.txt`](THIRD_PARTY_LICENSES.txt) using pinned tool
versions — `go-licenses/v2@v2.0.1` (via `go run`, no install needed) and
`license-checker-rseidelsohn@4.4.2` (via `npx --yes`; pinned to the 4.x
line deliberately — 5.x requires Node ≥24, and this repo pins Node 22 in
`.nvmrc`). Bump either pin deliberately, in the script, together with a
regeneration of both this file's inventory tables and
`THIRD_PARTY_LICENSES.txt` itself.

`go-licenses`' classifier treats any license it can't identify as
`Unknown` rather than failing outright when invoked via `report`. As of
this writing that happens for `github.com/inconshreveable/log15` and its
`/v3`, `/v3/ext` sub-packages (pulled in by `golang.ngrok.com/ngrok`) — a
short-form Apache-2.0 notice the text-similarity classifier doesn't match
against the canonical template. The script overrides these explicitly
(see its `case` statement); any *other* unclassified dependency fails the
script's run loudly rather than being silently skipped, naming the
package so it can be verified by hand and added to the override.

A handful of npm packages (e.g. `@vue/devtools-api`) declare a license in
`package.json` but ship no license file in their published tarball. For
those, a hand-verified copy of the real upstream license text lives in
[`scripts/license-overrides/npm/`](scripts/license-overrides/npm/) — the
script fails, naming the exact override path to create, if it hits an
npm package with neither a shipped license file nor an override.
