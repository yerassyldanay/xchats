# Қауіпсіздік саясаты

## Осалдық туралы қалай хабарлау керек

**Қауіпсіздік осалдығы туралы ашық GitHub issue жасамаңыз.**

[GitHub-тағы жеке осалдық туралы
хабарлау](https://github.com/yerassyldanay/xchats/security/advisories/new)
арқылы жеке хабарлаңыз (осы репозиторийдің **Security** қойындысы →
**Report a vulnerability**).

Мүмкіндігінше мыналарды көрсетіңіз:

- Мәселенің түрі (мысалы, тіркелгі деректерінің ағуы, авторизацияны айналып
  өту, инъекция, қызмет көрсетуден бас тарту).
- Қайталау қадамдары немесе proof of concept.
- Тексерілген нұсқа/commit.
- Түсінігіңізше әсері — шабуылдаушы нақты не істей алар еді.

## Нені күту керек

xchats арнайы қауіпсіздік маманы жоқ шағын команда тарапынан
қолдау көрсетіледі, сондықтан адал негіз — бекітілген SLA емес, мүмкіндігінше
жұмыс:

- **Хабарламаны алғанын растау:** 5 жұмыс күні ішінде.
- **Алғашқы бағалау** (расталды / осалдық емес / қосымша ақпарат керек): 10
  жұмыс күні ішінде.
- **Түзету мерзімі:** ауырлық дәрежесі бағаланғаннан кейін хабарланады —
  сыни мәселелер (қашықтан тіркелгі деректерінің/деректердің ағуы,
  авторизацияны айналып өту) жұмыстағы барлық басқа нәрседен басым болады.

## Қолданылу аясы

**Аясына кіреді:**

- Осы репозиторийден құрастырылған Go қызметі `backend/` және Vue қосымшасы
  `frontend/`.
- `deploy/` ішіндегі Docker образдары, жарияланған түрде (егер/қашан
  жарияланса — қараңыз
  [`docs/release/release-checklist.md`](../../release/release-checklist.md)).

**Аясына кірмейді:**

- Үшінші тарап тәуелділіктерінің өздеріндегі осалдықтар — олар туралы сол
  тәуелділіктің әзірлеушілеріне хабарлаңыз (тізім —
  [`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md) құжатында),
  дегенмен xchats осал тәуелділік нұсқасын қалай *пайдаланатыны* туралы
  хабарлама — қош келдіңіз.
- Нақты орналастырудың операциялық қауіпсіздігі (жаңартылмаған ОЖ, ашық
  дерекқор порты, ешқашан ауыстырылмаған bootstrap әкімші құпия сөзі —
  неге ауыстыру керектігі туралы қараңыз
  [`docs/release/installation.md`](../../release/installation.md)) — бұл
  xchats-тың өз осалдығы емес, оператордың жауапкершілігі, дегенмен
  әдепкі бойынша қауіпсіз емес баптауды ықтималдырақ ететін құжаттама
  олқылықтары туралы хабарлауға болады.
- xchats тек шақыратын үшінші тарап инфрақұрылымына (ngrok, LLM
  провайдерлері, GitHub API) қарсы әлеуметтік инженерия, физикалық қолжетімділік
  немесе қызмет көрсетуден бас тарту.

## Қолдау көрсетілетін нұсқалар

Тұрақты релиздер тарихы пайда болғанша тек соңғы шығарылған нұсқа мен
`master` қолдау көрсетіледі. Бұл бөлім тегтелген релиздер пайда болғанда
жаңартылады — қараңыз
[`docs/release/release-checklist.md`](../../release/release-checklist.md).

## Белгілі, әдейі жасалған қауіпсіздік компромисстері (осалдықтар емес)

Бұларды алдын ала құжаттаймыз, олар қайта табылған осалдық ретінде
хабарланбауы үшін — әрқайсысы кездейсоқтық емес, айқын, құжатталған жобалау
шешімі:

- **ngrok туннелі бүкіл қосымшаны, тек API allowlist-ін емес, қызмет
  етеді** — кіру бетін қоса алғанда — жұмыс істеп тұрған кезде. Мұны
  [`plan/DECISIONS.md`](../../../plan/DECISIONS.md) құжатының 2026-08
  туннель түзетуінде тіркелген; cookie-лердің туннельдің HTTPS-і арқылы
  `Secure` жалауын алуымен және туннельді бастар алдында интерфейстегі
  анық ескертумен жеңілдетіледі. Қараңыз
  [`docs/release/troubleshooting.md`](../../release/troubleshooting.md).
- **Файлға негізделген тіркелгі деректері қоймасы OS keychain-нен
  әлсіз** — ол дискіде шифрланған, бірақ ОЖ деңгейіндегі қолжетімділік
  бақылауынсыз, әрі пайдаланар алдында анық қосу
  (`XCHATS_ALLOW_FILE_CREDENTIALS=1`) және интерфейстегі растауды талап
  етеді. Қараңыз
  [`docs/release/credentials.md`](../../release/credentials.md).
- **Bootstrap әкімші тіркелгі деректері — бір реттік, кездейсоқ
  генерацияланған құпия сөз**, алғашқы іске қосу кезінде тек иесіне ғана
  қолжетімді (`0600`) файлға жазылады және `xchats admin-credential show`
  командасымен алынады (ешқашан лог ағынына шығарылмайды) — ортақ әдепкі
  құпия сөз емес. Тіркелгі алғашқы кіру кезінде құпия сөзді ауыстыруды
  міндетті түрде талап етеді, bootstrap файлы дереу осыдан кейін жойылады,
  ал `xchats reset-admin-password` қажет болған жағдайда оны қайта
  генерациялайды. [`docs/release/installation.md`](../../release/installation.md)
  құжатында сипатталған.

## WhatsApp қосылымы

xchats WhatsApp-қа [whatsmeow](https://github.com/tulir/whatsmeow) арқылы
қосылады — бұл ресми WhatsApp Business API емес, бейресми, кері инжиниринг
жасалған клиент. Бұл өнімнің осалдығы емес, саналы компромисі, бірақ оның
нақты айтылуға тұрарлық салдары бар: WhatsApp қосылған нөмірді өз қалауы
бойынша, дәлелдеусіз бұғаттай алады. Жоғалтуға дайын емес нөміріңізді
қоспаңыз.

## Алғыс білдіру

Бұл саясат іске қосылып, хабарламалар түсе бастаған соң, хабарлаушылар
(олардың келісімімен) осында аталады — адал хабарламалар үшін шағын, бірақ
шынайы алғыс ретінде.
