What it is

A workspace for talking to your customers

xchats pulls your messaging conversations into one shared inbox, keeps customer profiles and follow-ups, and runs bulk campaigns. The AI assistant drafts replies only from your verified knowledge base — it cannot invent a price or a delivery time: code fills in the numbers.

Everything stays with you: on your own computer or server, with no telemetry.

How one request flows through
1
The customer writes

On WhatsApp or Telegram. The message lands in the team's shared inbox right away.

2
The assistant drafts a reply

The draft is built from the knowledge base: products, tariffs, delivery, contacts. What it doesn't know it never makes up — it hands the conversation to a person.

3
A person approves

An operator edits and sends the reply. Auto-reply can be switched on per channel for chosen hours — at night, say.

Features

Everything you need to work with customers

Nine sections of the app — from the first message to campaigns and answer-quality checks.

Inbox

The shared team inbox: conversations from every channel, assignment to teammates, Mine / Unassigned / All filters. Next to each chat — the assistant's draft reply.

Customers

A profile for every contact: status, tags, notes, history and linked channels.

Follow-ups

Every promised next step becomes a task: overdue, today, tomorrow, later. Overdue ones show in the menu.

Campaigns

Bulk sending to a recipient list with pauses between messages, send windows and delivery tracking.

Knowledge base

Products with photos and prices, tariffs, delivery zones, contacts and policies — the assistant's only source of facts.

Draft

Every knowledge-base edit — from you, ChatGPT or Claude — lands here first as before/after and is published only after review.

Check

The simulator: ask as a customer and see the answer on the live knowledge base or the draft — no real phone number needed.

Channels

WhatsApp by QR code and Telegram bots: connection state, AI suggestions and an auto-reply schedule for each channel.

Settings

AI engine (OpenAI, Claude, Gemini, OpenRouter, Ollama), remote access, team and roles, backups.

Response templates

Not one made-up number

The model is forbidden from writing numbers. It emits a placeholder — code substitutes the exact value from the knowledge base.

How much is the DeLonghi coffee machine, and when can you deliver to Astana?

The DeLonghi coffee machine costs 129,900 ₸. Delivery to Astana — 2 days.

The model never writes a number — code fills it in. An unknown placeholder means an error and a handoff to a human, never a guess.

Desktop app

No Docker. No servers. Just download and run.

xchats ships as a standalone native desktop application for Windows, macOS, and Linux. The embedded SQLite database, Go backend, and Vue web interface are all packaged into a single executable.

Windows xchats-desktop-windows-amd64-installer.exe

Installer. Pick the install folder, get Start Menu and desktop shortcuts, and a clean uninstaller — no administrator rights needed.

Download or the portable archive: xchats.exe (portable)
macOS xchats-desktop-macos-universal.dmg

Universal disk image, native on Apple Silicon (M1/M2/M3/M4) and Intel Macs. Open it and drag xchats to /Applications.

Download or the portable archive: xchats.app (portable)
Linux xchats-desktop-linux-amd64.deb

Debian/Ubuntu package. Installs to /usr/bin and adds it to your application menu: sudo apt install ./xchats-desktop-linux-amd64.deb

Download or the portable archive: xchats (portable)

Not code-signed yet — Windows SmartScreen and macOS Gatekeeper will warn on first launch; on macOS, right-click the app and choose Open to proceed.

Looking for server deployment? You can also run xchats on a remote VPS or home lab via make up or pre-built container images.

Under the hood

Built to stay simple, fast and yours

No hosted dependencies, no subscription walls, no proprietary lock-in — built from day one for operators who run their own tools.

One binary, embedded SQLite

Written in Go with an embedded database (modernc.org/sqlite). No Postgres, Redis, or broker required — back it up by copying one file.

Local-first privacy

Your conversations, message history, contacts and knowledge base live exclusively on your machine or server. Zero external telemetry.

Model & platform agnostic

Swap between OpenAI, Claude, Gemini, OpenRouter, or a local self-hosted Ollama model directly from Settings.
