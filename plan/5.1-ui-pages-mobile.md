# UI Pages — Mobile

Companion to [`5-ui-pages.md`](5-ui-pages.md). **Same design language, same backing, same cases** — only
the **layout** adapts to a narrow **portrait phone** (~390 px). Nothing here re-specifies data or
endpoints; every element is backed exactly as in the desktop doc (see each page's **▸ Backed by** there).
Each mobile case is a **separate screen to generate an image for**; drop renders into
[`./ui/`](ui/) using the `ui/m-*.png` filenames.

> **Two hard rules still hold.** (1) **Style is constant; only layout+content vary** — reuse the mobile
> STYLE preamble verbatim. (2) **Every element is backed** — if it isn't in `5-ui-pages.md`'s backing, it
> isn't here either.

---

## What changes on mobile (the transform)

Everything visual (colors, type, components, accent, «Черновик» semantics, backing) is **identical** to
the desktop doc. Only the **shell and multi-pane layouts** collapse:

| Desktop | Mobile |
|---|---|
| Far-left **icon nav rail** | **bottom tab bar** (Инбокс · Номера · Конструктор · База знаний + avatar) |
| **Master-detail** side by side (chat list ┆ chat view) | **stacked push navigation** — list screen → tap → full-screen detail with a **back arrow** |
| **Right side-panels / rails** (assistant panel, «Обзор базы знаний») | **bottom sheets** (drag-handle, slide up over the screen) |
| **Modal dialogs** (QR) | **full-screen sheets** |
| **Horizontal tab strip** (KB editor) | **horizontally scrollable segmented tabs** (or a Select) |
| **FAB** loose bottom-right | **FAB** bottom-right, lifted **above the tab bar** |
| Four columns (Chatboard) | **three stacked screens**: list → chat → AI sheet |

Detail screens (a chat, a KB editor form) **hide the bottom tab bar** and show a **top bar with a back
arrow**; list/hub screens **show the tab bar**.

### Mobile STYLE preamble (prepend to every case)
```
High-fidelity flat MOBILE UI mockup: a single portrait phone screen, straight-on, thin neutral phone
frame, a minimal status bar at the top. Product: "XChats", a WhatsApp team-inbox + AI-assistant app.
Style: Linear-minimal, shadcn/Tailwind. LIGHT theme: cool near-white #F8FAFC background, white cards,
ink #0F172A text, grey #64748B secondary. ONE accent — indigo #4F46E5 — buttons, active tab, focus,
unread badges. WhatsApp green #22C55E ONLY for outbound chat bubbles, the WhatsApp glyph, and the
"connected" status dot — never on buttons. Hairline 1px borders, tight 8px corners, NO gradients, soft
shadows only on sheets/menus. Inter font, crisp dense typography. Russian-language UI. Avatars = white
initials on a colored circle (never photos). Portrait 9:19.5, single ~390px-wide column.
```

### Bottom-tab-bar block (prepend for hub/list screens — NOT for detail screens)
```
BOTTOM TAB BAR fixed at the bottom, white with a hairline top border: four line-icon tabs with tiny
labels — "Инбокс" (inbox icon), "Номера" (WhatsApp glyph), "Конструктор" (blocks/bot), "База знаний"
(library) — plus a round user-avatar at the far right; the active tab's icon and label are indigo, the
rest grey.
```

### Tips
- **Portrait, ~1080×2340 (9:19.5). One screen per image.** Include a subtle status bar; no browser chrome.
- **Reference the desktop `./ui/*.png`** of the same page as a style anchor, then say "mobile portrait,
  single column" — it keeps the look consistent while re-flowing the layout.
- Cyrillic may garble; you're capturing **layout + navigation pattern**, not final copy.
- Optional dark variant: append *"DARK theme: deep cool-charcoal #0B0F17 surfaces, lifted indigo."*

## Out of scope (mobile, v1)

Same exclusions as `5-ui-pages.md` (no reports, campaigns, presence, i18n switcher, etc.). Additionally,
**no mobile-only features** (no push notifications, no offline, no native app — this is the responsive
web SPA). Not shown, not stubbed.
