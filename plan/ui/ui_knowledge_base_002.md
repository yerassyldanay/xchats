### Knowledge Base

A clean, modern SaaS dashboard inspired by Linear, Notion, and Vercel, using a light theme with generous whitespace, rounded cards, subtle shadows, and a single purple accent color. The interface prioritizes readability and simplicity over dense enterprise layouts, making the knowledge base feel approachable while remaining professional.

The page consists of a compact left navigation sidebar, a header with search and primary action, a row of summary statistic cards, and a tab navigation that switches between different knowledge base entities. Each tab represents a logical section of the compiled knowledge base rather than a separate feature.

**Tabs:**

* Overview
* Topics
* Products
* Tariffs
* Delivery Zones
* Media Resources
* Contacts
* Policies

Each section is presented as a collection of large, easy-to-scan cards with minimal visual noise. Icons are colorful but subtle, typography is the primary visual hierarchy, and every card exposes only the most important information with secondary actions hidden behind contextual menus. The overall design should feel like a modern content management system built specifically for AI knowledge management rather than a traditional CRUD admin panel.
